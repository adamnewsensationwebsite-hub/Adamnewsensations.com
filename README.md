# New Sensations — Massage with Adam

Official website for **New Sensations**, a massage therapy practice run by Adam, based in Central & West London.

🔗 **Live site:** https://newsensations.co.uk *(update if your final domain differs)*

## About

This is a single, self-contained HTML page (no build step, no external dependencies besides Google Fonts) covering:

- Treatments & pricing
- The 5-session package offer
- Client reviews and FAQs
- Direct WhatsApp booking for every treatment
- Contact details and Instagram

## Structure

- `index.html` — the live site (standard version)
- `october.html` — seasonal offer variant, not currently live (kept for reference / reuse)

Everything — styling, images and the background video — is inlined into these files, so either one can be dropped into any static host with no configuration.

## Hosting

Hosted for free via **GitHub Pages**, served from the `main` branch at the repository root, with a custom domain attached through this repo's Pages settings (see the `CNAME` file).

## Making updates

1. Edit `index.html` directly (or ask Claude/a developer to make the change and re-export the file).
2. Commit and push the change to `main` — GitHub Pages redeploys automatically within a minute or two.
3. Hard-refresh (or check in a private browser window) to confirm the change is live, since browsers can cache the page.
